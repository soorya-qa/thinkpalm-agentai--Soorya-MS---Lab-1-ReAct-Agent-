# thinkpalm-agentai-SooryaMS-Lab 1-ReActAgent
**This project demonstrates a minimal Python ReAct agent that reasons step by step, uses a calculator tool, and answers a real‑world phone battery query, executed successfully in Google Colab.**

**User Query** -If my phone battery is 80% and it drains 10% per hour, how long will it last?

**How to Run:**

This project is designed to run in Google Colab using Python.
Steps to run:
Open Google Colab
Click New Notebook
Paste the Python code (ReAct agent) into a code cell
Click Run

**Tools Used:**
The project uses a simple calculator function as its only tool.

**Observatios:**
Observation: 8.0 hours
The phone battery will last approximately 8 hours.
